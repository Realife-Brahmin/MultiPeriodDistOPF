# OpenDSS network files

Looking for a feeder to try? Start with the
[test-network catalogue and quickstart](../test_networks/README.md).
It explains the systems, standalone downloads, shared profiles and citation.

These are the physical input paths used by the Julia drivers. Keep the shared
`LoadShape*.dss` files alongside the network folders. The catalogue uses the
friendlier name `test_networks` without changing existing code/data paths.
