# Archived first-order DDP

Retired on October 18, 2026. This is the independently developed 2025
first-order copper-plate algorithm, not the active SPAR-DDP solver.

- `original/`: original environment, driver, plotter and formulation.
- `examples/`: later minimal restatement and first-order diagnostics.

Files are preserved unchanged for provenance. Historical relative paths,
includes and environment commands describe their original locations; these
are not supported runnable entry points in the archive. The original
location was `envs/ddp/`; the later examples lived under
`ddp/examples/power_system/`. Supporting copper-plate result records remain
in the active workstream's historical results collection.

Do not use this archive for new experiments or interpret its environment
as a second supported DDP environment.
