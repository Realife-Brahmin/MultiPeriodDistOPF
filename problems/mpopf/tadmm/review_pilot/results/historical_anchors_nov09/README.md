uses preserved one-second registered-process samples within measured phase
events. MUMPS PSS peaks (central / all tADMM compute processes) are3.183/24.732 GiB

MUMPS-factorization-only memory. Native swap/paging was not sampled.

iterations. Current MUMPS5.9.0 completes T48 in30 iterations. Historical T24

not alone explain the time change. Corrected model/data, initialization,
redundant-row removal, bounds representation and backend version also differ;
no ablation separates their contributions, and old-PC paging has not been
established from the available evidence.
