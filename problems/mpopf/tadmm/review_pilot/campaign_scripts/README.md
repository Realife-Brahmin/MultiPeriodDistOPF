# Campaign scripts, November 9-11

Launch, collection, audit and summary scripts of the Kamiak campaigns of
November 9-11. They were committed in the repository root and moved here on
2026-11-15 to keep the root clean. Contents are unchanged except in five Python
scripts that locate the repository from their own path
(`analyze-anchor-stragglers`, `collect-anchor-iteration-cost`,
`collect-anchor-memory`, `plot-anchor-stragglers`,
`plot-sequential-discrepancies`), which now look five levels up.

The campaign notes written at the time (`*_NOV09.md` and the result READMEs
beside them) cite these scripts by their old root path, for example
"repository-root `audit-socp-storage-nov09.py`". Read those as
`campaign_scripts/<name>`. The frozen source copies on Kamiak keep the old
layout.

New scripts go in this folder or beside the code they drive, never in the root.
