Structural, not statistical
Independent of all three trends above: the terminal stage's multi-RHS block is exactly rank-deficient in a way none of the interior stages are — every one of its nx state-sensitivity columns has singular value exactly 1.0, at every sampled iteration, on all three systems. The terminal stage carries no incoming value curvature and its only state-dependence is the per-battery energy-slack identity, so this is an exact structural fact, not a fitted approximation — that stage's solve is a candidate for row selection instead of a dense multi-column KKT solve.
